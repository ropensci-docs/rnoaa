# autoplot method for meteo_coverage objects

autoplot method for meteo_coverage objects

## Usage

``` r
autoplot_meteo_coverage(meteo_object, old_style = FALSE)
```

## Arguments

- meteo_object:

  the object returned from
  [`meteo_coverage()`](https://docs.ropensci.org/rnoaa/reference/meteo_coverage.md)

- old_style:

  (logical) create the old style of plots, which is faster, but does not
  plot gaps to indicate missing data

## Value

A ggplot2 plot

## Details

see
[`meteo_coverage()`](https://docs.ropensci.org/rnoaa/reference/meteo_coverage.md)
for examples.
