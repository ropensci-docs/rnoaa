# Clear *meteo* cached files

The *meteo* functions use an aplication

## Usage

``` r
meteo_clear_cache(force = FALSE)
```

## Arguments

- force:

  (logical) force delete. default: `FALSE`

## Note

This function will clear all cached *meteo* files.
