# Check object class

Check if an object is of class ncdc_data, ncdc_datasets, ncdc_datatypes,
ncdc_datacats, ncdc_locs, ncdc_locs_cats, or ncdc_stations

## Usage

``` r
is.ncdc_data(x)

is.ncdc_datasets(x)

is.ncdc_datatypes(x)

is.ncdc_datacats(x)

is.ncdc_locs(x)

is.ncdc_locs_cats(x)

is.ncdc_stations(x)
```

## Arguments

- x:

  input
